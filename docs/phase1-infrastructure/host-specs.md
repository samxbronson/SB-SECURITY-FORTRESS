# Host Machine Specifications

## Purpose
Document the hardware and software specifications of the host machine used for development and virtualization environments.

## Specifications

### Hardware
- **CPU**: Ryzen 7 5800x (8 Cores)
- **RAM**: 32GB DDR4
- **Storage**: eSSD SanDisk 1TB (500GB Free)
- **Network**: Ethernet, 1Gbps

### Software
- **OS**: Windows 11 Pro 25H2
- **Hypervisor**: VMware Workstation Pro 17
