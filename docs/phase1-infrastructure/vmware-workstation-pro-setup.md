# VMware Workstation Pro Setup

## Purpose
VMware Workstation Pro setup is part of the SB-SECURITY-FORTRESS homelab project, serving as the foundational virtualization platform for the security-focused lab environment. This setup enables the creation and management of virtual machines required for Active Directory deployment, security monitoring with SIEM, vulnerability management, and system hardening activities.
